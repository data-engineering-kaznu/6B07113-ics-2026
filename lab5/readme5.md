Лабораторная работа №5: Создание рекомендательных систем (MovieLens)

📋 Описание
Цель лабораторной работы — изучить основные методы построения рекомендательных систем и применить их для анализа пользовательских оценок фильмов.

В работе используются два основных подхода:

Content-Based Filtering — рекомендации на основе характеристик объектов (жанров фильмов).

Collaborative Filtering (User-Based) — рекомендации на основе сходства пользователей и их оценок.

Также выполняется оценка качества рекомендаций и визуализация результатов.

🛠 Используемые библиотеки

pandas — работа с таблицами и CSV файлами.

numpy — математические вычисления и работа с массивами.

scikit-learn — вычисление косинусного сходства и метрики качества.

matplotlib — построение графиков и визуализация рекомендаций.

📂 Структура файлов

icslab5.py — основной скрипт программы, реализующий рекомендательную систему.

input5.csv — входной файл с пользовательскими рейтингами фильмов
(поля: userId, movieId, rating, timestamp).

input5.1.csv — файл с информацией о фильмах
(поля: movieId, title, genres).

output5.csv — файл с результатами рекомендаций для пользователей.

⚙️ Как использовать

Установить необходимые библиотеки (если они ещё не установлены):

pip install pandas numpy scikit-learn matplotlib

Разместить файлы:

input5.csv
input5.1.csv
icslab5.py

в одной папке.

Запустить программу:

python icslab5.py
📊 Результаты работы программы

После выполнения программы будут получены:

output5.csv — таблица с рекомендациями фильмов для пользователей
(поля: userId, movieId, title).

График рекомендаций — столбчатая диаграмма, показывающая самые часто рекомендуемые фильмы.

Также в консоли выводится метрика качества рекомендаций:

RMSE

которая показывает среднюю ошибку предсказания рейтингов.

📈 Используемые методы рекомендательных систем

Content-Based Filtering

Рекомендации формируются на основе сходства фильмов по жанрам.

Collaborative Filtering (User-Based)

Рекомендации формируются на основе сходства пользователей и их оценок фильмов.

Cosine Similarity

Используется для вычисления степени сходства между пользователями и объектами.
