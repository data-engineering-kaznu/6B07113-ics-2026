Рекомендательная система на основе Book-Crossing Dataset
Описание

Этот проект представляет собой простую рекомендательную систему для книг, реализованную на Python с использованием двух подходов:

Collaborative Filtering — рекомендации на основе сходства пользователей.

Content-Based (опционально) — можно добавлять рекомендации на основе характеристик книги (автор, издатель).

Для работы используется датасет Book-Crossing, содержащий информацию о пользователях, книгах и выставленных оценках.

Структура проекта
├─ BX-Book-Ratings.csv   # Данные о рейтингах пользователей
├─ BX-Books.csv          # Информация о книгах (название, автор, издатель)
├─ lab_recommendation.py # Основной скрипт с реализацией рекомендаций
├─ README.md             # Описание проекта
Используемые библиотеки

pandas — работа с таблицами и CSV

numpy — числовые вычисления

scikit-learn — косинусная мера сходства, метрика RMSE

matplotlib — визуализация графиков

Описание кода

Загрузка данных
Считываются CSV файлы с информацией о книгах и оценках пользователей.

Подвыборка и предобработка
Для ускорения работы выбирается случайная часть данных и исключаются нулевые рейтинги.

Матрица User × Book
Создается таблица, где строки — пользователи, столбцы — книги, а значения — рейтинги.

Collaborative Filtering

Рассчитывается косинусная мера сходства между пользователями.

На основе оценок похожих пользователей формируется топ-рекомендаций для каждого пользователя.

Оценка модели
Используется метрика RMSE, которая показывает среднюю ошибку предсказания рейтингов.

Визуализация
Строится график с топ-рекомендациями для выбранного пользователя с отображением названий книг и предсказанных рейтингов.

Вывод

Проект демонстрирует базовую реализацию рекомендательной системы на реальных данных.
Использование двух CSV-файлов позволяет формировать рекомендации с наглядной информацией о книгах.
Метрика RMSE показывает, насколько точно система предсказывает оценки пользователей.
Визуализация помогает наглядно оценить результаты рекомендаций.
