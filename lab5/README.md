Лабораторная работа: Рекомендательные системы

Цель работы



Целью данной лабораторной работы является изучение принципов работы рекомендательных систем и реализация алгоритмов рекомендаций на основе пользовательских данных.



Постановка задачи



В рамках лабораторной работы необходимо:



выбрать набор данных



реализовать рекомендательную систему на основе содержимого (Content-Based Filtering)



реализовать рекомендательную систему на основе коллаборативной фильтрации (Collaborative Filtering)



оценить качество рекомендаций с помощью метрик



выполнить визуализацию результатов



Используемый датасет



В работе используется датасет MovieLens, содержащий информацию о фильмах и оценках пользователей.



Файл movies.csv



Содержит информацию о фильмах.



Поле	Описание

movieId	идентификатор фильма

title	название фильма

genres	жанры фильма



Пример записи:



1,Toy Story (1995),Adventure|Animation|Children|Comedy|Fantasy

Файл ratings.csv



Содержит оценки пользователей.



Поле	Описание

userId	идентификатор пользователя

movieId	идентификатор фильма

rating	оценка пользователя

timestamp	время выставления оценки



Пример записи:



1,1,4.0

Используемые методы

Content-Based Filtering



Контентный подход строит рекомендации на основе характеристик объектов.



В данной работе фильмы сравниваются по их жанрам.

Для преобразования жанров в числовой формат используется CountVectorizer.



После этого вычисляется cosine similarity, которая позволяет определить степень сходства между фильмами.



На основе этого пользователю предлагаются фильмы с похожими характеристиками.



Collaborative Filtering



Коллаборативная фильтрация строит рекомендации на основе поведения пользователей.



Основная идея метода заключается в том, что пользователи с похожими предпочтениями могут получать похожие рекомендации.



Алгоритм работы:



строится матрица пользователь–фильм



вычисляется сходство между пользователями



предсказываются рейтинги фильмов



пользователю предлагаются фильмы с наибольшим предсказанным рейтингом



Метрики оценки качества

RMSE



RMSE (Root Mean Square Error) — корень из средней квадратичной ошибки.



Данная метрика показывает, насколько предсказанные рейтинги отличаются от реальных оценок пользователей.



Чем меньше значение RMSE, тем точнее работает модель.



Precision@K



Precision@K показывает долю релевантных рекомендаций среди первых K предложенных объектов.



Например:



Precision@5 = 2 / 5 = 0.4
