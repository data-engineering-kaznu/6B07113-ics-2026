# Лабораторная работа №4: Создание рекомендательных систем

## Цель работы
Изучение и практическая реализация основных подходов к построению рекомендательных систем: контентной фильтрации (Content-based) и коллаборативной фильтрации (User-based), а также оценка их эффективности с помощью математических метрик.

## Используемый набор данных
В работе использован классический датасет **MovieLens (ml-latest-small)**, содержащий:
- 100,000 оценок;
- 9,742 фильма;
- Данные от 610 пользователей.

## Реализованные алгоритмы

### 1. Контентный подход (Content-based Filtering)
Алгоритм анализирует характеристики объектов (жанры фильмов). 
- **Метод:** Использование векторного представления текста (TF-IDF) для жанров.
- **Сходство:** Косинусное сходство (Cosine Similarity) между векторами признаков.

### 2. Коллаборативная фильтрация (User-based)
Рекомендации строятся на основе истории оценок похожих пользователей.
- **Метод:** Построение матрицы "Пользователь-Объект".
- **Алгоритм:** Предсказание рейтинга на основе средневзвешенного отклонения оценок похожих пользователей.

## Метрики качества
Для оценки точности предсказаний в работе рассчитываются:
* **RMSE (Root Mean Square Error):** Среднеквадратичная ошибка предсказания рейтинга.
* **Precision@K:** Точность рекомендаций в топ-K выдаче.
* **Recall@K:** Полнота рекомендаций среди релевантных объектов.
