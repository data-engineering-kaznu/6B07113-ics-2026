# Лабораторная работа 15: Глубокое обучение и сверточные нейронные сети

## Цель

Разобраться с базовыми принципами работы сверточных нейронных сетей и реализовать простую CNN-подобную модель для классификации изображений.

## Используемые методы и подходы

- чтение входных данных и запись результатов в CSV средствами стандартного модуля `csv`;
- представление изображений как матриц 4x4 пикселей;
- применение свёрток с небольшими ядрами для выделения признаков;
- использование функции активации ReLU и операции глобального max pooling;
- обучение выходного классификатора по извлечённым признакам.

## Краткое описание выполнения

Файл `input15.csv` содержит набор маленьких изображений, представленных 16 пикселями (`p0` ... `p15`) и меткой класса `label`.

Скрипт `icslab15.py`:

1. считывает и проверяет входные данные;
2. преобразует каждую строку в изображение 4x4;
3. применяет два свёрточных фильтра для извлечения признаков;
4. выполняет ReLU и max pooling;
5. обучает компактный классификатор и сохраняет результаты в `output15.csv`.

Такой пример показывает основную идею CNN: сначала выделяются признаки свёртками, затем по ним выполняется классификация. Решение остаётся простым, компактным и запускается без внешних библиотек.

## Файлы проекта

- `icslab15.py` — основной исполняемый скрипт;
- `input15.csv` — входной набор изображений;
- `output15.csv` — результаты классификации;
- `readme15.md` — описание лабораторной работы.

## Запуск

```bash
python icslab15.py
```

После запуска программа обрабатывает входной набор и перезаписывает `output15.csv` актуальными результатами.
