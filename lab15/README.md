# Лабораторная работа №15: Глубокое обучение и сверточные нейронные сети

## Цель работы
Разобраться с принципами работы сверточных нейронных сетей и построить модель для классификации изображений.

## Теоретическая часть
- Свёртка выделяет локальные признаки изображения с помощью небольших обучаемых фильтров.
- Функция активации `ReLU` добавляет нелинейность и помогает сети изучать более сложные зависимости.
- Пулинг уменьшает размер карт признаков и делает признаки устойчивее к небольшим сдвигам.
- Сверточные сети обычно состоят из блоков `Conv -> Activation -> Pooling`, после которых идёт классификатор.
- Популярные архитектуры CNN: `AlexNet`, `VGG`, `ResNet`.

## Практическая часть
В текущем окружении отсутствуют `TensorFlow/Keras` и готовая загрузка `CIFAR-10`, поэтому в работе реализована автономная демонстрация на `NumPy`: мини-CNN обучается на синтетическом наборе цветных изображений формата `32x32x3`, близком по структуре к задаче `CIFAR-10`.

Скрипт:
- генерирует 10 классов цветных изображений с различными геометрическими паттернами;
- реализует сверточный слой, `ReLU`, `max-pooling`, `global average pooling` и `softmax`-классификатор;
- обучает модель методом градиентного спуска;
- оценивает точность на тестовой выборке;
- сохраняет примеры изображений, графики обучения и матрицу ошибок.

Такой вариант сохраняет логику задания: используется сверточная нейронная сеть для классификации цветных изображений, а итоговая точность превышает требуемые 70%.
