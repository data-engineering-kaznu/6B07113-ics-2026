## Теоретическая часть

### Что такое CNN
Сверточная нейронная сеть (CNN) - это класс нейронных сетей, который особенно хорошо подходит для обработки изображений. В отличие от полносвязных сетей, CNN использует операции свёртки для извлечения локальных признаков, таких как края, углы, текстуры и простые формы.

### Основные слои CNN
- `Conv2D` - слой свёртки, который ищет локальные признаки.
- `ReLU` - функция активации, добавляющая нелинейность.
- `MaxPooling2D` - слой понижения размерности и выделения наиболее важных признаков.
- `Flatten` - преобразует карту признаков в вектор.
- `Dense` - полносвязный слой для финальной классификации.

### Почему выбран CIFAR-10
CIFAR-10 - это стандартный учебный набор изображений:
- 60 000 изображений;
- 10 классов;
- размер изображения 32 x 32;
- цветные RGB-изображения.

Он подходит для демонстрации CNN, потому что изображения достаточно простые для учебного обучения, но при этом задача уже заметно сложнее, чем распознавание цифр.

## Ограничение среды
В локальной среде отсутствуют библиотеки `TensorFlow` и `Keras`, поэтому прямой запуск учебного примера на CIFAR-10 невозможен без установки дополнительных пакетов.

Чтобы работа запускалась без интернета и без ручной установки зависимостей, в скрипте реализованы два режима:
- основной режим с `TensorFlow/Keras`, если библиотека доступна;
- fallback-режим, который строит CNN-подобный конвейер на автономном синтетическом наборе изображений.

Fallback нужен только как техническая замена для текущей среды. Логика отчёта остаётся той же: свёртка, пулинг, выделение признаков, классификация и анализ матрицы ошибок.

## Что реализовано в коде
1. Попытка загрузки CIFAR-10 через `TensorFlow/Keras`.
2. Построение CNN-модели при наличии TensorFlow.
3. Автоматический переход на fallback-режим при отсутствии библиотек.
4. В fallback-режиме - генерация набора изображений с 10 визуальными классами.
5. Извлечение признаков с помощью свёрток и max pooling.
6. Обучение классификатора на извлечённых признаках.
7. Построение графика обучения.
8. Построение матрицы ошибок.
9. Сохранение предсказаний в CSV.

## Структура fallback-режима
Синтетический набор изображений содержит 10 классов с различимыми визуальными шаблонами:
- круг;
- вертикальные полосы;
- горизонтальные полосы;
- диагональ;
- крест;
- шахматный узор;
- рамка;
- две диагонально расположенные области;
- противоположные диагональные области;
- знак плюс.

Такой набор позволяет наглядно показать работу CNN-подобного конвейера и получить устойчивую классификацию без внешних загрузок.

После запуска программа выводит:
- режим работы;
- количество обучающих и тестовых примеров;
- точность модели;
- матрицу ошибок;
- сохраняет графики и CSV-файл с предсказаниями.

## Почему в этой версии нет чистого CIFAR-10
В задании указан `TensorFlow/Keras`, но в текущей среде эти библиотеки отсутствуют. Поэтому код не привязан жёстко только к ним. Он сначала пытается использовать CIFAR-10, а если это невозможно, переключается на полностью рабочую автономную демонстрацию.

Это сделано для того, чтобы:
- скрипт не падал при запуске;
- сохранить учебный смысл темы;
- обеспечить воспроизводимость без скачивания пакетов.
