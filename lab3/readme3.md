Лабораторная работа №2: Классификация с ансамблевыми методами (Wine Quality)

📋 Описание
Цель лабораторной работы — предсказать качество вина (quality) на основе химических характеристик вина с использованием ансамблевых методов.
Используются:

Random Forest (Bagging) — ансамблевая модель, объединяющая множество деревьев решений.

Decision Tree — базовая модель для сравнения производительности.

🛠 Используемые библиотеки

pandas — работа с таблицами и CSV файлами.

scikit-learn — модели машинного обучения, метрики, разделение данных.

matplotlib — визуализация важности признаков.

os — работа с путями к файлам.

📂 Структура файлов

classification.py — исходный код с обучением моделей и сохранением предсказаний.

Input3.csv — входной файл с характеристиками вина и целевой переменной quality.

Output3.csv — файл с тестовыми признаками, реальными значениями качества и предсказаниями Random Forest.

feature_importance.png — график важности признаков, построенный Random Forest.

⚙️ Как использовать

Установить библиотеки (если ещё не установлены):

pip install pandas scikit-learn matplotlib

Разместить Input3.csv и classification.py в одной папке.

Запустить скрипт:

python classification.py

После выполнения будут созданы:

Output3.csv — предсказания модели.

feature_importance.png — график важности признаков.

В консоли будет выведена точность базовой модели (Decision Tree) и ансамблевой модели (Random Forest).
