Проект по предсказанию одобрения кредита

В этом проекте мы сравниваем два подхода машинного обучения для задачи бинарной классификации: Bagging (Random Forest) и Boosting (XGBoost).

Что сделано

Загружены и подготовлены данные по заемщикам, включая доход, сумму займа и кредитную историю.

Категориальные признаки закодированы с помощью LabelEncoder.

Данные разделены на обучающую и тестовую выборки.

Реализованы и обучены модели:

Random Forest (Bagging)

XGBoost (Boosting)

Проведена оценка моделей с использованием метрик:

Accuracy — точность предсказаний

ROC-AUC — способность модели различать положительные и отрицательные классы

Построены графики для:

Сравнения Accuracy и ROC-AUC моделей

Важности признаков для каждой модели

В проекте использовались такие библиотеки как pandas, numpy, matplotlib, scikit-learn, xgboost.
