\# Titanic Survival Prediction (Bagging / Random Forest)



\# Описание

В данной лабораторной работе реализована задача классификации

для предсказания выживания пассажиров Титаника.



В работе используется базовая модель Logistic Regression

и ансамблевый метод Bagging в виде Random Forest.



\# Цель работы

\- Загрузить датасет Titanic

\- Выполнить предобработку данных

\- Заполнить пропущенные значения

\- Закодировать категориальные признаки

\- Разделить данные на train и test

\- Обучить базовую модель Logistic Regression

\- Обучить ансамблевую модель Random Forest

\- Сравнить точность моделей

\- Построить график важности признаков



\# Используемый датасет

Titanic Dataset



Датасет содержит информацию о пассажирах:

\- пол

\- возраст

\- класс билета

\- стоимость билета

\- количество родственников на борту

\- порт посадки



Целевая переменная:

Survived — выжил пассажир или нет

\# Вывод

В результате работы сравниваются две модели классификации:

Logistic Regression и Random Forest.



Random Forest как ансамблевый метод bagging обычно показывает

более высокую точность, так как использует несколько деревьев решений

и уменьшает вероятность переобучения.



График важности признаков показывает, какие характеристики пассажиров

сильнее всего влияют на предсказание выживания.
