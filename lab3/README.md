# Данные

В работе используется датасет **Iris** из репозитория :contentReference[oaicite:0]{index=0}.

Ссылка на источник: https://archive.ics.uci.edu/ml/datasets/iris

Набор данных содержит:

**150 наблюдений**

**4 числовых признака:**

- sepal_length — длина чашелистика  
- sepal_width — ширина чашелистика  
- petal_length — длина лепестка  
- petal_width — ширина лепестка  

**1 категориальный признак:**

- class — вид цветка

**3 класса (вида цветков):**

- Iris-setosa  
- Iris-versicolor  
- Iris-virginica  

Файл `iris.data` размещён в корневой папке проекта.

---

# Описание

Данная лабораторная работа демонстрирует решение задачи **обучения без учителя** с использованием алгоритмов кластеризации и метода снижения размерности.

В ходе работы выполняются следующие этапы:

- загрузка данных из CSV-файла;
- отделение признаков от меток классов;
- нормализация признаков;
- кластеризация данных алгоритмами K-means и DBSCAN;
- снижение размерности методом PCA;
- визуализация кластеров;
- оценка качества кластеризации.

---

# Предобработка данных

Перед применением алгоритмов данные проходят подготовку:

### Нормализация признаков
Применяется масштабирование с использованием **StandardScaler**:

- среднее значение = 0  
- стандартное отклонение = 1  

Это необходимо, поскольку алгоритмы кластеризации чувствительны к масштабу признаков.

---

# Модели кластеризации

## K-means

Алгоритм разбивает данные на **k кластеров** (в работе k = 3).

Принцип работы:

1. Случайно выбираются центры кластеров.
2. Каждая точка относится к ближайшему центру.
3. Центры пересчитываются как среднее точек кластера.
4. Шаги повторяются до стабилизации центров.

Особенности:

- Требует заранее задать число кластеров
- Хорошо работает с компактными группами объектов

---

## DBSCAN

Алгоритм плотностной кластеризации.

Принцип работы:

1. Выбирается точка.
2. Если рядом достаточно соседей (min_samples) в радиусе eps — образуется кластер.
3. Если соседей мало — точка считается шумом.

Особенности:

- Не требует задания числа кластеров
- Может находить кластеры произвольной формы
- Устойчив к выбросам

---

# Снижение размерности

## PCA (метод главных компонент)

Метод уменьшает число признаков, сохраняя максимальное количество информации.

В работе:

- исходная размерность: 4 признака
- новая размерность: 2 компоненты

Это позволяет визуализировать многомерные данные на плоскости.

---

# Оценка качества кластеризации

Используется метрика:

### Silhouette Score (коэффициент силуэта)

Показывает, насколько объекты:

- похожи на точки своего кластера
- отличаются от точек других кластеров

Диапазон значений:

- от −1 до 1
- ближе к 1 — хорошая кластеризация
- около 0 — кластеры пересекаются
- меньше 0 — ошибки кластеризации

# Результаты работы программы

### K-means:
Silhouette score = **0.4787**

Значение показывает **среднее качество кластеризации**.  
Кластеры различимы, но имеют пересечения.

### DBSCAN:
Silhouette score вычислить нельзя.

Причина:

- алгоритм обнаружил шумовые точки (метка **−1**)
- часть данных не вошла в кластеры
- метрика силуэта требует минимум 2 полноценных кластера без шумов

### Метки кластеров DBSCAN:

- 0 и 1 — найденные кластеры
- −1 — шум (выбросы)
