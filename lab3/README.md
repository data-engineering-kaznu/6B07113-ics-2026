# Лабораторная работа 3
## Распознавание образов с помощью обучения без учителя

### Цель работы
Изучить алгоритмы обучения без учителя, включая кластеризацию и методы снижения размерности, и применить их к задачам распознавания образов.

### Описание работы
В данной лабораторной работе используется датасет `Fashion-MNIST`, скачанный с платформы Kaggle.  
Датасет содержит изображения различных предметов одежды, представленные в виде числовых значений пикселей.

Каждое изображение имеет размер **28×28 пикселей** и представлено **784 признаками**.

В ходе работы были выполнены:
- загрузка датасета;
- предварительная обработка данных;
- кластеризация методом **K-means**;
- кластеризация методом **DBSCAN**;
- уменьшение размерности данных методом **PCA**;
- визуализация многомерных данных на плоскости;
- оценка качества кластеризации с помощью **метрики силуэта**.

### Используемые библиотеки
- numpy
- pandas
- matplotlib
- scikit-learn
