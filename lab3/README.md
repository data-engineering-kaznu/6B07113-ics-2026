# Лабораторная работа 3  
## Распознавание образов с помощью обучения без учителя

### Цель работы
Изучить алгоритмы обучения без учителя, включая методы кластеризации и снижения размерности.

### Использованные алгоритмы
- K-means
- DBSCAN
- PCA (метод главных компонент)

### Использованный датасет
В работе использовался датасет Iris из библиотеки scikit-learn.  
Он содержит 150 объектов и 4 признака, описывающих размеры частей цветка.

### Ход работы
1. Загрузка данных Iris.
2. Масштабирование данных.
3. Кластеризация с использованием алгоритма K-means.
4. Кластеризация с использованием алгоритма DBSCAN.
5. Снижение размерности данных методом PCA.
6. Визуализация кластеров.
7. Оценка качества кластеризации с помощью метрики silhouette score.

### Результаты
K-means:
- Кластер 0: 53 объектов
- Кластер 1: 50 объектов
- Кластер 2: 47 объектов
- Silhouette score: 0.4599

DBSCAN:
- Кластер 0: 49 объектов
- Кластер 1: 97 объектов
- Шум: 4 объектов
- Silhouette score: 0.5217
