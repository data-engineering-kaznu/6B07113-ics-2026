# Лабораторная работа 13: Искусственные нейронные сети

## Цель

Изучить базовые принципы искусственных нейронных сетей и реализовать простую многослойную нейронную сеть для задачи бинарной классификации.

## Используемые методы и подходы

- чтение и запись данных в формате CSV средствами стандартного модуля `csv`;
- реализация простой MLP (многослойного персептрона) на чистом Python;
- использование сигмоидной функции активации;
- обучение сети методом обратного распространения ошибки;
- проверка качества модели на тех же входных данных с записью предсказаний в `output13.csv`.

## Краткое описание выполнения

Входные данные находятся в файле `input13.csv` и содержат три столбца: `x1`, `x2`, `label`.
Скрипт `icslab13.py`:

1. считывает строки из `input13.csv`;
2. проверяет корректность формата и значений;
3. обучает компактную нейронную сеть с одним скрытым слоем;
4. вычисляет предсказания для всех входных примеров;
5. сохраняет результаты обработки в `output13.csv`.

В качестве демонстрационного набора данных используется задача XOR, для которой однослойный персептрон недостаточен, поэтому применение MLP здесь оправдано и наглядно.

## Файлы проекта

- `icslab13.py` — основной исполняемый скрипт;
- `input13.csv` — входной набор данных;
- `output13.csv` — файл с результатами классификации;
- `readme13.md` — описание лабораторной работы.

## Запуск

```bash
python icslab13.py
```

После запуска программа обучает модель и перезаписывает `output13.csv` актуальными результатами.
