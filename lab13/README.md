# Лабораторная работа №13: Искусственные нейронные сети

## Цель работы
Разобраться с базовыми принципами искусственных нейронных сетей и реализовать многослойный персептрон для задачи классификации изображений.

## Теоретическая часть
- Персептрон — простейшая нейронная модель, которая вычисляет взвешенную сумму входов и применяет функцию активации.
- Многослойный персептрон (MLP) состоит из входного слоя, одного или нескольких скрытых слоёв и выходного слоя.
- Функция активации `ReLU` помогает сети моделировать нелинейные зависимости.
- Обратное распространение ошибки используется для обновления весов сети во время обучения.

## Практическая часть
В работе реализована автономная демонстрация классификации рукописных цифр с помощью `MLPClassifier` из `scikit-learn`.

Скрипт:
- загружает встроенный набор данных `digits`;
- делит выборку на обучающую и тестовую части;
- обучает многослойную нейронную сеть;
- оценивает точность классификации;
- сохраняет примеры изображений, матрицу ошибок и график функции потерь.

Такой вариант соответствует логике задания: используется MLP-модель для распознавания изображений, а итоговая точность превышает требуемые 90%.

## Файлы
- `lab13.py` — основной скрипт.
- `digit_samples.png` — примеры изображений из набора данных.
- `confusion_matrix.png` — качество классификации на тестовой выборке.
- `loss_curve.png` — изменение ошибки во время обучения.

## Как запустить
```bash
python lab13.py
```

## Ожидаемый результат
Скрипт выводит размер выборки, точность модели, примеры предсказаний и отчёт по классам, а также сохраняет визуальные результаты в папку `lab13`.
