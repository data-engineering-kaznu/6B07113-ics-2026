## Теоретическая часть

### Персептрон
Персептрон - это простейшая нейронная модель, которая вычисляет взвешенную сумму входов и затем применяет функцию активации. Один нейрон способен решать только линейно разделимые задачи.

### Многослойный персептрон (MLP)
Многослойный персептрон состоит из:
- входного слоя;
- одного или нескольких скрытых слоев;
- выходного слоя.

За счёт скрытых слоев сеть может аппроксимировать сложные нелинейные зависимости между входными признаками и целевыми метками.

### Функция активации
В данной работе используется функция активации `ReLU`. Она задаётся как:

`f(x) = max(0, x)`

Она помогает сети обучаться быстрее и лучше работать с нелинейными зависимостями.

### Обратное распространение ошибки
Во время обучения сеть сравнивает свои предсказания с правильными ответами, вычисляет ошибку и затем корректирует веса. Этот процесс называется обратным распространением ошибки.

## Архитектура модели
В лабораторной работе использована нейронная сеть со следующими параметрами:
- скрытые слои: `(128, 64)`;
- функция активации: `relu`;

- максимальное число итераций: `300`;
- ранняя остановка: включена.

Такая конфигурация достаточна для уверенной классификации небольшого набора изображений цифр.
