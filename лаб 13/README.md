# Лабораторная работа 13

Тема: искусственные нейронные сети.

В работе реализована простая MLP-модель для классификации рукописных цифр MNIST.

Что делает программа:

- загружает датасет MNIST;
- нормализует изображения;
- переводит метки классов в формат one-hot;
- обучает нейронную сеть с одним скрытым слоем;
- выводит точность на тестовой выборке.

Используемые библиотеки:

- Python;
- TensorFlow/Keras или Keras.

Запуск:

```bash
python lab13.py
```

Ожидаемый результат: точность классификации на тестовых данных больше 90%.
