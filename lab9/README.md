# Лабораторная работа 9

Тема: обработка естественного языка.

В работе реализована базовая обработка текстового корпуса и построение
языковой N-граммной модели.

Что делает программа:

- загружает встроенный текстовый корпус;
- выполняет токенизацию;
- удаляет стоп-слова;
- рассчитывает частоты слов;
- строит биграммную языковую модель;
- оценивает модель с помощью perplexity.

Особенности реализации:

- используется простая предобработка без внешних библиотек;
- применяется сглаживание Лапласа для вероятностей N-грамм;
- выводятся наиболее вероятные продолжения для выбранного контекста.

Запуск:

```bash
python lab9.py
```

Структура:

- `lab9.py` — основная программа лабораторной работы;
- `README.md` — краткое описание.
