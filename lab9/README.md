# ЛЗ 15: Глубокое обучение и сверточные нейронные сети (CNN)

Реализация CNN для классификации изображений на датасете CIFAR-10.

- Архитектура: 2 блока Conv2D → MaxPooling → Dropout + Dense классификатор
- Датасет: CIFAR-10 (60,000 цветных изображений 32×32, 10 классов)
- **Результат: точность ≥ 70% на тестовых данных**

```
python lab15.py
```

## Установка зависимостей

```
pip install -r requirements.txt
```
