# Лабораторная работа 15

Тема: глубокое обучение и сверточные нейронные сети.

В работе реализована CNN-модель для классификации изображений CIFAR-10.

Что делает программа:

- загружает датасет CIFAR-10;
- нормализует изображения;
- переводит метки классов в формат one-hot;
- обучает сверточную нейронную сеть;
- выводит точность на тестовой выборке.

Используемые библиотеки:

- Python;
- TensorFlow/Keras или Keras.

Запуск:

```bash
python lab15.py
```

Ожидаемый результат: точность на тестовых данных около 70% или выше.
