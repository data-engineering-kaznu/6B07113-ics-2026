# KNN Classification (Iris Dataset)

# Описание
В данной лабораторной работе реализован алгоритм классификации K-ближайших соседей (KNN).
Используется датасет Iris из библиотеки sklearn.

# Цель работы
- Загрузить датасет
- Проверить данные на пропуски
- Разделить данные на train и test
- Нормализовать признаки
- Обучить модель KNN
- Оценить качество модели

# Используемый датасет
Iris Dataset

Количество объектов: 150  
Количество признаков: 4  
Количество классов: 3  

Классы растений:
- Setosa
- Versicolor
- Virginica

# Используемые библиотеки
- numpy
- scikit-learn

# Метрики оценки
- Accuracy
- Precision
- Recall
- F1-score
- Cross-validation (5-fold)

# Алгоритм работы
1. Загрузка датасета Iris
2. Проверка пропущенных значений
3. Разделение данных на обучающую и тестовую выборки
4. Нормализация признаков (StandardScaler)
5. Обучение модели KNN
6. Предсказание на тестовой выборке
7. Расчет метрик качества
8. Кросс-валидация модели

# Запуск проекта

Установить зависимости

pip install numpy scikit-learn

Запустить программу

python main.py

# Вывод
Модель KNN показывает высокую точность классификации на датасете Iris.
Кросс-валидация подтверждает стабильность результатов модели.
