# KNN Iris Classifier

Этот проект демонстрирует использование алгоритма **K-ближайших соседей (KNN)** для классификации цветков ириса на основе их признаков (длина и ширина лепестка и чашелистика).  

Данные загружаются из CSV-файлов:
- `input.csv` — признаки (features)  
- `output.csv` — классы (target)  

---

## Используемые библиотеки
- `pandas` — для работы с CSV  
- `numpy` — для числовых операций  
- `scikit-learn` — для модели KNN и метрик качества  

Установить библиотеки:

bash
Копировать код

В терминале появятся метрики качества модели и отчёт по каждому классу.

Метрики качества
Accuracy — точность модели

Precision — точность предсказаний

Recall — полнота модели

F1-score — гармоническое среднее Precision и Recall

Classification report — подробный отчёт по каждому классу

Cross-validation — проверка модели на 5 частях данных (5-fold)

Источники данных
