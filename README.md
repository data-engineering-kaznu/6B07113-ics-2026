#Данные
В работе используется датасет Iris из UCI Machine Learning Repository.
Ссылка на источник: https://archive.ics.uci.edu/ml/datasets/iris
Набор данных содержит: 150 наблюдений
4 числовых признака:
  sepal_length — длина чашелистика
  sepal_width — ширина чашелистика
  petal_length — длина лепестка
  petal_width — ширина лепестка
3 класса (виды цветков):
  Iris-setosa
  Iris-vrsicolor
  Iris-virginica
Файл iris.data размещён в корневой папке проекта.


#Описание
Данная лабораторная работа демонстрирует полный процесс решения задачи классификации методом обучения с учителем с использованием алгоритма ближайших соседей (KNN).
В ходе работы выполняются следующие этапы:
  загрузка данных из CSV-файла;
  кодирование категориальных меток классов в числовой формат;
  обработка пропущенных значений заменой на среднее;
  нормализация признаков с использованием StandardScaler;
  разделение данных на обучающую и тестовую выборки;
  обучение модели классификации KNN;
  оценка качества модели.

#Предобработка данных
Перед обучением модели данные проходят подготовку:
1.Кодирование классов
  Строковые значения классов преобразуются в числовые категории.
2. Обработка пропусков
  Пропущенные значения заменяются средним значением соответствующего признака.
3. Масштабирование признаков
  Применяется нормализация, приводящая признаки к единому масштабу
  (среднее значение 0, стандартное отклонение 1).
  Это необходимо, поскольку алгоритм KNN использует расстояние между объектами.

#Модель
Используемый алгоритм:
  K-ближайших соседей (KNN)
  число соседей: k = 5
Модель определяет класс объекта на основе голосования ближайших соседей в пространстве признаков.

#Оценка качества
Качество классификации оценивается с использованием:
Accuracy — доля правильно классифицированных объектов;
Confusion Matrix — матрица ошибок классификации;
Classification Report:
  Precision
  Recall
  F1-score
Эти метрики позволяют подробно проанализировать результат работы модели.
