# Лабораторная работа №11: Создание систем распознавания речи

## Цель работы
Познакомиться с обработкой аудиосигналов и базовым распознаванием речевых команд на основе MFCC-признаков.

## Практическая часть
В этой работе реализована автономная демонстрация распознавания команд без внешних аудиофайлов:

- синтезируются аудиосигналы для команд `forward`, `backward`, `stop`;
- вручную вычисляются MFCC-признаки через БПФ, mel-фильтры и DCT;
- обучается простая нейросетевая модель `MLPClassifier`;
- сохраняются визуализации MFCC и матрицы ошибок.

Такой вариант покрывает ключевые этапы задания:
загрузка/подготовка аудио, извлечение MFCC и построение модели распознавания набора слов.

## Файлы
- `lab11.py` — основной скрипт.
- `mfcc_example.png` — пример MFCC для одной команды.
- `confusion_matrix.png` — качество классификации на тестовой выборке.

## Как запустить
```bash
python lab11.py
```

## Ожидаемый результат
Скрипт выводит точность классификации, отчёт по классам и предсказание для тестового сигнала, а также сохраняет графики в папку `lab11`.
