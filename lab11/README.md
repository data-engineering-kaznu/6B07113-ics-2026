# ЛЗ 11. Создание систем распознавания речи

## Цель работы

Ознакомиться с основами обработки аудиосигналов и построения модели для распознавания речи.

## Теоретическая часть

### 1. Аудиосигнал

Аудиосигнал представляет собой последовательность отсчетов амплитуды звука во времени. Для компьютерной обработки звук обычно переводится в цифровой вид с заданной частотой дискретизации.

### 2. Преобразование Фурье

Преобразование Фурье позволяет перейти от временного представления сигнала к частотному. Это помогает определить, какие частоты присутствуют в аудиозаписи.

### 3. MFCC-признаки

MFCC (Mel-frequency cepstral coefficients) используются для компактного описания речи. Они учитывают особенности человеческого слуха и часто применяются в задачах распознавания команд, слов и фраз.

Основные этапы получения MFCC:

- разбиение сигнала на короткие окна
- вычисление спектра для каждого окна
- применение мел-фильтров
- логарифмирование энергии
- получение кепстральных коэффициентов

### 4. Модель распознавания речи

Для распознавания речи аудиосигнал преобразуется в признаки, после чего классификатор определяет, к какому слову или команде относится запись. В данной работе используется простая нейронная сеть, реализованная на `NumPy`.

## Практическая часть

В работе реализована демонстрационная система распознавания трех голосовых команд:

- `forward`
- `back`
- `stop`

Так как внешний набор аудиоданных не требуется, программа создает синтетические аудиосигналы для каждой команды. Затем выполняются:

1. генерация обучающих и тестовых аудиосигналов
2. извлечение MFCC-признаков
3. обучение простой нейронной сети
4. оценка точности распознавания
5. визуализация сигнала, MFCC-признаков, ошибки обучения и матрицы ошибок
