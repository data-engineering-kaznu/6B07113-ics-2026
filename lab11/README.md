В папке используется учебный датасет с уже подготовленными MFCC-признаками.

Столбцы:
- `sample_id` - номер примера.
- `command` - целевая команда.
- `mfcc_1 ... mfcc_13` - 13 MFCC-признаков, описывающих аудиосигнал.

Команды в датасете:
- `forward`
- `back`
- `stop`
- `left`
- `right`

Всего в датасете 40 примеров. Для каждой команды подготовлено по 8 образцов.

## Теоретическая часть
### Что такое MFCC
MFCC (Mel-Frequency Cepstral Coefficients) - это набор признаков, который часто используется в задачах распознавания речи. Они позволяют представить аудиосигнал в компактном виде, близком к тому, как человек воспринимает звук.

### Почему именно MFCC
Сырые аудиоданные неудобно подавать в модель напрямую. MFCC помогают выделить важные характеристики речи и уменьшить размерность данных.

### Нейронная сеть
В этой работе используется простая нейронная сеть `MLPClassifier`. Это многослойный персептрон, который обучается различать команды по MFCC-признакам.

## Что реализовано в коде
1. Загрузка датасета с MFCC-признаками.
2. Выделение признаков и целевой переменной.
3. Масштабирование данных с помощью `StandardScaler`.
4. Кодирование текстовых меток команд в числовой формат.
5. Разделение на обучающую и тестовую выборки.
6. Обучение нейронной сети для классификации команд.
7. Оценка качества модели по accuracy.
8. Построение матрицы ошибок и графика распределения классов.

## Ход выполнения работы
1. Подготовлен компактный датасет с MFCC-признаками для 5 команд.
2. Данные приведены к единому масштабу.
3. Нейронная сеть обучена на обучающей части выборки.
4. На тестовой выборке выполнено распознавание команд.
5. Результаты представлены в текстовом виде и с помощью графиков.

В задании требуется изучить принцип работы систем распознавания речи. Для этого достаточно использовать уже извлеченные MFCC-признаки, так как именно они поступают в модель на этапе обучения.

- извлекать MFCC автоматически через `librosa`;
- заменить простую нейронную сеть на LSTM или другую последовательностную модель.
