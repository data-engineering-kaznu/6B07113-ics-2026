# Лабораторная работа №12: Обнаружение и отслеживание объектов

📋 Описание
Цель лабораторной работы — изучить методы компьютерного зрения для обнаружения и отслеживания объектов на видео.

В работе используется подход отслеживания объекта на основе алгоритмов OpenCV.
Пользователь вручную выбирает объект на первом кадре, после чего программа автоматически отслеживает его перемещение на протяжении всего видео.

🛠 Используемые библиотеки

* OpenCV — обработка видео и реализация алгоритмов отслеживания объектов
* csv — чтение и запись CSV файлов

📂 Структура файлов

* icslab12.py — основной скрипт программы
* input12.csv — входной файл с данными (путь к видео)
* output12.csv — файл с результатами отслеживания
* video.mp4 — видеофайл для обработки

⚙️ Как использовать

1. Установить необходимые библиотеки:

pip install opencv-python numpy

2. Разместить файлы:

* input12.csv
* icslab12.py
* video.mp4

в одной папке.

3. Запустить программу:

python icslab12.py

4. На первом кадре выделить объект мышкой и нажать Enter.

📊 Результаты работы программы

После выполнения программы будут получены:

* output12.csv — файл с координатами объекта на каждом кадре
  (поля: frame, x, y, width, height)

На экране отображается видео с прямоугольником, показывающим отслеживаемый объект.

📈 Используемые методы

Object Tracking (KCF / CSRT)

Алгоритмы отслеживания объектов из библиотеки OpenCV позволяют определять положение объекта на каждом кадре видео после его начального выделения.

Bounding Box

Для отображения объекта используется ограничивающая рамка (прямоугольник), которая обновляется на каждом кадре.

Computer Vision

Область искусственного интеллекта, связанная с обработкой изображений и видео.

🎯 Вывод

В ходе работы были изучены основные методы отслеживания объектов на видео.
Реализована программа, позволяющая отслеживать выбранный объект и сохранять его координаты в файл.
Полученные результаты демонстрируют эффективность алгоритмов компьютерного зрения.
