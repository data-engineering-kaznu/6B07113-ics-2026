# Лабораторная работа №12: Обнаружение и отслеживание объектов

## Цель работы
Освоить базовый конвейер компьютерного зрения: обнаружение объекта на кадре и его отслеживание по видеопоследовательности.

## Практическая часть
В этой работе реализована автономная демонстрация без веб-камеры и без OpenCV:

- генерируется синтетическая видеопоследовательность с движущимся объектом;
- объект обнаруживается по цветовой маске;
- положение отслеживается по кадрам и накапливается траектория;
- сохраняются изображения с детекцией, итоговой траекторией и GIF-анимация трекинга.

Такой вариант соответствует логике задания: загрузка видео-последовательности, обнаружение объекта и его дальнейшее отслеживание.

## Файлы
- `lab12.py` — основной скрипт.
- `detection_preview.png` — обнаружение объекта на первом кадре.
- `trajectory.png` — итоговая траектория движения.
- `tracking_demo.gif` — анимация отслеживания.

## Как запустить
```bash
python lab12.py
```

## Ожидаемый результат
Скрипт выводит долю успешно отслеженных кадров и среднюю ошибку трекинга, после чего сохраняет визуальные результаты в папку `lab12`.
