\# Linear Regression (House Price Prediction)



\# Описание

В данной лабораторной работе реализована модель линейной регрессии

для предсказания стоимости домов на основе датасета kc\_house\_data.



\# Цель работы

\- Загрузить датасет

\- Очистить и подготовить данные

\- Разделить данные на train и test

\- Нормализовать признаки

\- Обучить модель линейной регрессии

\- Оценить качество модели



\# Используемый датасет

kc\_house\_data



Датасет содержит информацию о продаже домов:

\- цена дома (price)

\- количество комнат

\- площадь

\- этажность

\- год постройки

\- и другие характеристики



Целевая переменная:

price — стоимость дома



\# Используемые библиотеки

\- pandas

\- numpy

\- scikit-learn



\# Метрики оценки

\- Mean Squared Error (MSE)

\- R2 Score

\- Cross-validation (5-fold)



\# Алгоритм работы

1\. Загрузка датасета kc\_house\_data.csv

2\. Удаление ненужных колонок (id, date)

3\. Проверка данных на пропуски

4\. Разделение на признаки и целевую переменную

5\. Разделение данных на обучающую и тестовую выборки

6\. Нормализация признаков (StandardScaler)

7\. Обучение модели LinearRegression

8\. Предсказание значений

9\. Расчет метрик качества

10\. Кросс-валидация модели

11\. Сохранение результатов в output.csv



\# Запуск проекта



Установить зависимости



pip install pandas numpy scikit-learn



Запустить программу



python main.py



\# Вывод

Модель линейной регрессии позволяет предсказывать стоимость домов

на основе характеристик недвижимости. Метрики MSE и R2 показывают

качество работы модели. Кросс-валидация используется для оценки

устойчивости модели
