# Лабораторная работа №2: Регрессия (California Housing)

## 📋 Описание задания
В данной работе реализована задача регрессии. Цель — предсказать непрерывную величину (медианную стоимость жилья в районах Калифорнии) на основе социально-экономических и географических данных.

## 🛠 Методология
* **Алгоритм:** Линейная регрессия (Linear Regression).
* **Предобработка:** * Масштабирование признаков (StandardScaler) для корректной работы линейной модели.
    * Разделение данных на обучающий и проверочный наборы.
* **Метрики оценки:**
    * **MSE (Mean Squared Error):** Среднеквадратичная ошибка.
    * **R² (Коэффициент детерминации):** Показывает долю объясненной дисперсии.

## 📊 Результаты
* Построен график сравнения реальных цен и предсказанных моделью.
* Модель позволяет оценить вклад каждого признака (например, доход населения) в итоговую стоимость жилья.

## 📂 Структура файлов
* `regression.py` — исходный код.
* `Input_reg.csv` — данные о жилье.
* `Output_reg.csv` — сравнение реальных цен и предсказаний.
