# Данные

В работе используется датасет **California Housing** из библиотеки Scikit-learn.

Источник набора данных: встроенный датасет California Housing.

Набор данных содержит:

**20640 наблюдений**

**8 числовых признаков:**

- MedInc — медианный доход жителей района  
- HouseAge — средний возраст домов  
- AveRooms — среднее количество комнат  
- AveBedrms — среднее количество спален  
- Population — численность населения района  
- AveOccup — среднее число жильцов в доме  
- Latitude — широта  
- Longitude — долгота  

**Целевая переменная:**

- MedHouseVal — медианная стоимость домов в районе

Файл `california_housing_train.csv` размещён в корневой папке проекта.

---

# Описание

Данная лабораторная работа демонстрирует полный процесс решения задачи **регрессии** методом обучения с учителем с использованием алгоритма линейной регрессии.

В ходе работы выполняются следующие этапы:

- загрузка данных из CSV-файла;
- разделение признаков и целевой переменной;
- обработка пропущенных значений;
- нормализация признаков;
- разделение данных на обучающую и тестовую выборки;
- обучение модели линейной регрессии;
- оценка качества модели;
- визуализация результатов.

---

# Предобработка данных

Перед обучением модели данные проходят подготовку:

### Обработка пропусков
Пропущенные значения заменяются средним значением соответствующего признака.

### Масштабирование признаков
Применяется нормализация с использованием StandardScaler, приводящая признаки к единому масштабу:

- среднее значение = 0  
- стандартное отклонение = 1  

Масштабирование необходимо, чтобы признаки с разными диапазонами значений одинаково влияли на модель.

### Разделение выборки
Данные делятся на:

- обучающую выборку — 80%
- тестовую выборку — 20%

---

# Модель

Используемый алгоритм:

**Линейная регрессия**

Линейная регрессия строит модель зависимости целевой переменной от признаков в виде линейной функции.

Модель предсказывает стоимость домов на основе характеристик района.

---

# Оценка качества

Качество регрессии оценивается с использованием следующих метрик:

### Mean Squared Error (MSE)
Среднеквадратичная ошибка показывает средний квадрат разницы между реальными и предсказанными значениями.

### R² Score (коэффициент детерминации)

Показывает, насколько хорошо модель объясняет данные:

- R² = 1 — идеальная модель
- R² = 0 — модель не лучше среднего
- R² < 0 — модель работает плохо

---

# Визуализация результатов

Строится график рассеяния:

- по оси X — реальные значения стоимости домов
- по оси Y — предсказанные значения

Если модель работает идеально, точки располагаются вдоль диагональной линии.

График позволяет наглядно оценить точность предсказаний модели.
