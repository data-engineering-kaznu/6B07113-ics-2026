# Лабораторная работа №2: Линейная регрессия

Этот проект посвящен построению модели линейной регрессии для прогнозирования цен на жилье на основе набора данных **USA Housing Dataset**.

## 📂 Структура папки lab2
* **data/** — содержит исходный датасет в формате CSV.
* **script/** — содержит Python-скрипт `regression.py` с реализацией модели.

## 🛠️ Описание реализации
В ходе работы были выполнены следующие шаги:
1.  **Загрузка данных**: Данные считываются из CSV-файла с использованием библиотеки `pandas`.
2.  **Предобработка**: 
    * Удалены нечисловые признаки (`date`, `street`, `city`, `statezip`), которые не могут быть обработаны моделью.
    * Данные разделены на признаки (X) и целевую переменную (Price).
3.  **Нормализация**: Использован `StandardScaler` для приведения признаков к единому масштабу.
4.  **Обучение**: Данные разделены на обучающую и тестовую выборки (80/20). Модель обучена с помощью `LinearRegression` из библиотеки `sklearn`.

## 📊 Результаты
Модель оценивается по двум метрикам:
* **MSE (Mean Squared Error)**: Среднеквадратичная ошибка предсказания.
* **R2 Score**: Коэффициент детерминации, показывающий точность аппроксимации.
