# Лабораторная работа №2: Регрессия с ансамблевыми методами (California Housing)

📋 Описание

Цель лабораторной работы — предсказать медианную стоимость жилья (MedHouseVal) на основе социально-экономических характеристик районов Калифорнии с использованием ансамблевых методов регрессии.

В работе используются два алгоритма:

* Random Forest Regressor — ансамблевая модель на основе множества деревьев решений.
* XGBoost Regressor — градиентный бустинг для задач регрессии.

Результаты моделей сравниваются по метрикам качества и визуализируются с помощью графиков.

---

🛠 Используемые библиотеки

* pandas — работа с таблицами и сохранение CSV файлов.
* numpy — численные вычисления.
* matplotlib — визуализация результатов и важности признаков.
* scikit-learn — загрузка датасета, разбиение данных, модель Random Forest и метрики качества.
* XGBoost — модель градиентного бустинга для регрессии.

Используемые модули:

* fetch_california_housing
* train_test_split
* RandomForestRegressor
* XGBRegressor
* mean_squared_error, r2_score

---

📂 Структура проекта

* regression.py — основной файл с кодом:

  * загрузка датасета California Housing
  * сохранение входных данных в Input_reg.csv
  * разбиение данных на обучающую и тестовую выборки
  * обучение моделей Random Forest и XGBoost
  * получение предсказаний
  * расчет метрик качества
  * сохранение результатов в Output_reg.csv
  * построение графиков и важности признаков

* Input_reg.csv — входной файл с признаками и целевой переменной MedHouseVal.

* Output_reg.csv — файл с реальными значениями цены и предсказаниями моделей.

⚙️ Как использовать


---

📊 Результаты работы программы

После запуска будут получены:

* Input_reg.csv — таблица с исходными данными.
* Output_reg.csv — таблица со столбцами:

  * Actual_Price — реальная цена жилья
  * Pred_RF — предсказание Random Forest
  * Pred_XGB — предсказание XGBoost
  * Diff_RF — абсолютная ошибка Random Forest
  * Diff_XGB — абсолютная ошибка XGBoost

В консоли выводятся метрики качества:

* MSE (Mean Squared Error) — среднеквадратичная ошибка
* R² — коэффициент детерминации

Пример вывода:

```
Random Forest -> MSE: 0.2560, R²: 0.81
XGBoost -> MSE: 0.2300, R²: 0.83
```

Также строятся графики:

* Реальная цена vs Предсказанная цена для двух моделей
* Важность признаков для Random Forest и XGBoost
