# Лабораторная работа №1: Классификация методом k-ближайших соседей (Iris Dataset)

📋 Описание

Цель лабораторной работы — классифицировать виды ирисов на основе их признаков (длина и ширина чашелистика и лепестка) с использованием алгоритма k-ближайших соседей (KNN).

В работе используется встроенный набор данных Iris из библиотеки машинного обучения.

Модель:

* KNeighborsClassifier (k = 3) — алгоритм классификации на основе ближайших соседей.

Перед обучением данные масштабируются с помощью стандартизации.

---

🛠 Используемые библиотеки

* pandas — создание таблицы с результатами предсказаний.
* scikit-learn — загрузка датасета Iris, разбиение данных, масштабирование признаков, обучение модели и расчет метрик качества.

Используемые модули:

* load_iris
* train_test_split
* StandardScaler
* KNeighborsClassifier
* accuracy_score, precision_score, recall_score, f1_score

---

📂 Структура проекта

* classification.py — основной файл с кодом:

  * загрузка датасета Iris
  * разделение данных на обучающую и тестовую выборки
  * масштабирование признаков
  * обучение модели KNN
  * получение предсказаний
  * вывод таблицы результатов и метрик качества

---

⚙️ Как использовать

1. Установить необходимые библиотеки (если они ещё не установлены):

```bash
pip install pandas scikit-learn
```

2. Сохранить код в файл:

```
classification.py
```

3. Запустить программу:

```bash
python classification.py
```

---

📊 Результаты работы программы

После запуска в консоли будет выведено:

* Таблица с данными тестовой выборки:

  * признаки цветка
  * реальный класс (Actual)
  * предсказанный класс (Predicted)

* Метрики качества классификации:

  * Accuracy — общая точность модели
  * Precision — точность по классам (macro-average)
  * Recall — полнота по классам (macro-average)
  * F1-score — гармоническое среднее Precision и Recall

Пример вывода:

```
Метрики качества
Accuracy: 0.98
Precision: 0.98
Recall: 0.98
F1-score: 0.98
```

---

📌 Вывод

В результате лабораторной работы была реализована модель классификации методом k-ближайших соседей для датасета Iris.
Модель показала высокую точность предсказаний, что подтверждает эффективность алгоритма KNN для задач классификации с небольшим числом признаков и объектов.
