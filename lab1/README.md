# ЛЗ 1. Классификация методом K-Ближайших Соседей (KNN)

## 📋 Описание
Этот проект демонстрирует решение задачи классификации с учителем (Supervised Learning) на примере датасета **Iris**.
Цель работы — обучить модель определять сорт цветка ириса по размерам его лепестков и чашелистиков.

**Используемый алгоритм:** K-Nearest Neighbors (KNN).

## 📂 Структура проекта
* **main.py** — основной код программы (загрузка, обработка, обучение, оценка).
* **Input.csv** — пример входных данных (сырые данные с характеристиками цветов).
* **Output.csv** — пример выходных данных (результаты предсказания модели).
* **README.md** — документация проекта.
