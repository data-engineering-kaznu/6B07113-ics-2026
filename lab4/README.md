# Данные

В работе используется датасет MovieLens 100K из GroupLens Research.

Ссылка на источник: https://grouplens.org/datasets/movielens/100k/

Набор данных содержит:

100 000 оценок фильмов

943 пользователя

1682 фильма

Основные файлы датасета:

u.data — оценки пользователей  
u.item — информация о фильмах  

---

# Описание

Данная лабораторная работа демонстрирует построение рекомендательных систем с использованием различных подходов машинного обучения.

В ходе работы выполняются следующие этапы:

загрузка данных о пользователях и фильмах;
формирование матрицы пользователь–фильм;
реализация коллаборативной фильтрации;
реализация контентной рекомендательной системы;
оценка качества рекомендаций;
визуализация результатов.

---

# Предобработка данных

Перед построением моделей данные проходят подготовку:

Формирование матрицы пользователь–фильм  
Строки соответствуют пользователям, столбцы — фильмам, значения — рейтинги.

Заполнение пропусков  
Пропущенные оценки заменяются нулями для вычисления схожести.

---

# Модели рекомендательных систем

## Коллаборативная фильтрация (User-Based)

Алгоритм рекомендует фильмы на основе схожести пользователей.

Принцип работы:

1. Вычисляется мера сходства между пользователями.
2. Находятся пользователи с похожими вкусами.
3. Предсказываются оценки фильмов на основе оценок похожих пользователей.

---

## Контентная фильтрация

Алгоритм рекомендует фильмы на основе их характеристик.

Принцип работы:

1. Анализируются жанры фильмов.
2. Определяются предпочтения пользователя.
3. Предлагаются фильмы с похожими характеристиками.

---

# Оценка качества

Используемая метрика:

RMSE — среднеквадратичная ошибка

Показывает отклонение предсказанных рейтингов от реальных.

Меньшее значение RMSE указывает на более точные рекомендации.

---

# Визуализация

Строится график рекомендованных фильмов для выбранного пользователя.

График показывает список фильмов, которые система считает наиболее подходящими.
