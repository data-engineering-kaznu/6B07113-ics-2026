\# Customer Segmentation (K-Means and DBSCAN)



\# Описание

В данной лабораторной работе реализована кластеризация клиентов

с помощью алгоритмов K-Means и DBSCAN.



Для анализа используется датасет Mall Customers.

Сравнение качества кластеризации выполняется с помощью silhouette score.



\# Цель работы

\- Загрузить датасет

\- Выбрать признаки для кластеризации

\- Нормализовать данные

\- Подобрать лучшее число кластеров для K-Means

\- Подобрать параметры для DBSCAN

\- Оценить качество кластеризации

\- Выполнить уменьшение размерности с помощью PCA

\- Построить графики кластеров



\# Используемый датасет

Mall\_Customers



Датасет содержит информацию о клиентах:

\- пол

\- возраст

\- годовой доход

\- показатель трат



Для кластеризации используются признаки:

\- Annual Income (k$)

\- Spending Score (1-100)



\# Используемые библиотеки

\- pandas

\- numpy

\- matplotlib

\- scikit-learn



\# Алгоритмы

\- K-Means

\- DBSCAN

\- PCA



\# Метрика оценки

\- Silhouette Score



\# Алгоритм работы

1\. Загрузка датасета Mall\_Customers.csv

2\. Выбор признаков Annual Income и Spending Score

3\. Нормализация данных с помощью StandardScaler

4\. Подбор лучшего числа кластеров для K-Means

5\. Обучение модели K-Means

6\. Подбор лучших параметров eps и min\_samples для DBSCAN

7\. Обучение модели DBSCAN

8\. Применение PCA для уменьшения размерности до 2 компонентов

9\. Построение графиков кластеризации для K-Means и DBSCAN

10\. Сравнение качества моделей по silhouette score

\# Вывод

В результате работы выполняется сегментация клиентов

на основе их годового дохода и уровня трат.



Алгоритм K-Means разбивает клиентов на заданное количество кластеров,

а DBSCAN ищет плотные группы объектов и может выделять шум.



Silhouette score позволяет сравнить качество кластеризации.

PCA используется для удобной визуализации кластеров на плоскости.
