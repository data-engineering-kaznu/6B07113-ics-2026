# ЛЗ 4. Создание рекомендательных систем

## Цель работы
Изучить основные подходы к построению рекомендательных систем, включая коллаборативную фильтрацию и методы на основе содержимого.

## Используемый датасет
MovieLens (Kaggle)

## Реализованные методы
- Content-Based Recommendation
- Collaborative Filtering (User-Based)

## Метрики качества
- RMSE
- Precision@5
- Recall@5

## Визуализация
Построены графики рекомендаций для отдельного пользователя.

pip install -r requirements.txt
