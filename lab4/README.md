Цель проекта:
Выявить сегменты клиентов по возрасту, доходу и «Spending Score» для понимания поведения покупателей.

Данные

Источник: CSV-файл

Используемые признаки:

Age — возраст

Annual Income (k$) — годовой доход в тысячах долларов

Spending Score (1-100) — балл активности/покупательской лояльности

Данные масштабированы (StandardScaler) для одинаковой шкалы признаков.

Методы кластеризации

KMeans (5 кластеров)

Алгоритм разбивает клиентов на 5 групп с минимальной внутрикластерной дисперсией.

Рассчитан Silhouette Score, показывающий качество разделения.

DBSCAN (eps=0.7, min_samples=5)

Находит плотные группы клиентов и помечает редкие точки как шум.

Silhouette Score считается только если есть больше одного кластера.

Уменьшение размерности и визуализация

PCA (2 компоненты)

Сокращает три признака до 2D для наглядной визуализации кластеров.

Графики:

KMeans Clusters (PCA)

Цвет точек = кластер KMeans.

Показывает распределение клиентов по 5 сегментам.

Кластеры выглядят компактными и круглыми.

DBSCAN Clusters (PCA)

Цвет точек = кластер DBSCAN, черные точки = шум.

Позволяет увидеть естественные плотные группы и выбросы.

Кластеры могут быть любой формы, не только круглые.

Основные выводы

KMeans хорошо подходит для фиксированного числа сегментов, дает стабильные, легко интерпретируемые кластеры.

DBSCAN выявляет плотные группы клиентов и шум, что полезно для обнаружения редких типов покупателей.

PCA-графики помогают визуально оценить структуру данных и качество кластеризации.

Сегментация клиентов может использоваться для таргетинга, маркетинговых кампаний и анализа поведения покупателей.
