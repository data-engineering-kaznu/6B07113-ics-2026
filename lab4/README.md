# Lab 4 — Recommender System

## Описание

В данной лабораторной работе реализована простая рекомендательная система на основе датасета **MovieLens Latest Small**.

Используются два подхода:

- **Content-Based Filtering** — рекомендации на основе жанров фильмов
- **Collaborative Filtering** — рекомендации на основе сходства пользователей

Также проводится оценка качества рекомендаций с помощью метрики **RMSE**.


# Dataset

Используется датасет **MovieLens Latest Small** с Kaggle.

Файлы:

- `movie.csv` — информация о фильмах
- `ratings.csv` — оценки пользователей
