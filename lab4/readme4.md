Лабораторная работа №4: Распознавание образов с помощью обучения без учителя (Customer Segmentation)

📋 Описание
Цель лабораторной работы — изучить алгоритмы обучения без учителя, применить кластеризацию и методы снижения размерности для анализа и сегментации данных клиентов.

Используются алгоритмы:

K-means — разделение данных на заданное количество кластеров.

DBSCAN — поиск плотных групп точек, выявление шумов.

PCA (Principal Component Analysis) — снижение размерности данных для визуализации в 2D пространстве.

🛠 Используемые библиотеки

pandas — работа с таблицами и CSV файлами.

scikit-learn — модели машинного обучения, метрики и методы кластеризации.

matplotlib — визуализация кластеров и результатов PCA.

📂 Структура файлов

clustering.py — исходный код с загрузкой данных, кластеризацией, PCA и сохранением результатов.

input4.csv — входной файл с данными клиентов (CustomerID, Gender, Age, Annual Income, Spending Score).

output4.csv — выходной файл с исходными данными, результатами кластеризации и координатами PCA.

KMeans_clusters.png — график кластеров, полученных методом K-means.

DBSCAN_clusters.png — график кластеров, полученных методом DBSCAN.

⚙️ Как использовать

Установить библиотеки (если ещё не установлены):

pip install pandas scikit-learn matplotlib

Разместить input4.csv и clustering.py в одной папке.

Запустить скрипт:

python clustering.py

После выполнения будут созданы:

output4.csv — таблица с исходными данными, колонками кластеров K-means и DBSCAN, а также координатами PCA.

KMeans_clusters.png — график визуализации кластеров K-means.

DBSCAN_clusters.png — график визуализации кластеров DBSCAN.

В консоли будут выведены Silhouette Score для оценки качества кластеров K-means и DBSCAN.
