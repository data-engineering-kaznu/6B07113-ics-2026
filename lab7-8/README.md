# ЛЗ 13-14: Нейронные сети и обучение с подкреплением

## ЛЗ 13 — Искусственные нейронные сети (MLP + MNIST)

Реализация многослойного персептрона с нуля на NumPy для классификации рукописных цифр.

- Архитектура: 784 → 128 (ReLU) → 10 (Softmax)
- Обучение: mini-batch градиентный спуск, backpropagation с нуля
- Датасет: MNIST (70,000 изображений цифр 0–9)
- **Результат: точность 95.77% (цель ≥ 90%)**

```
python lab13.py
```

## ЛЗ 14 — Обучение с подкреплением (Q-learning + CartPole)

Реализация Q-learning агента с нуля для задачи удержания шеста на тележке.

- Среда CartPole реализована на физических уравнениях Ньютона (без gym)
- Q-таблица: 10×10×20×20×2 = 80,000 ячеек
- Обучение: epsilon-greedy, 10,000 эпизодов
- **Результат: 500 шагов из 500 во всех тестах (цель ≥ 200)**

```
python lab14.py
```
