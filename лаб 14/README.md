# Лабораторная работа 14

Тема: обучение с подкреплением.

В работе реализован алгоритм Q-learning для среды CartPole.

Особенность CartPole в том, что состояние среды состоит из непрерывных чисел. Поэтому значения состояния разбиваются на интервалы, после чего для них строится Q-таблица.

Что делает программа:

- создает среду `CartPole-v1`;
- переводит наблюдения среды в дискретное состояние;
- обучает агента методом Q-learning;
- проверяет обученного агента без случайных действий;
- выводит количество шагов, которое агент смог удерживать баланс.

Используемые библиотеки:

- Python;
- NumPy;
- Gymnasium или Gym.

Запуск:

```bash
python lab14.py
```

Ожидаемый результат: агент должен удерживать баланс около 200 шагов или больше.
