# Лабораторная работа 10: Вероятностный подход к обработке последовательных данных

## Что реализовано

В файле `icslab10.py` реализована простая скрытая марковская модель (HMM) для анализа последовательностей наблюдений.

- Скрытые состояния: `Sunny`, `Rainy`.
- Наблюдения: `walk`, `shop`, `clean`.
- Используется алгоритм Витерби для поиска наиболее вероятной последовательности скрытых состояний.
- Результаты читаются из `input10.csv` и сохраняются в `output10.csv`.
- В `output10.csv` также записывается простая ASCII-визуализация вероятностей переходов между состояниями.

## Формат входного файла

`input10.csv` содержит столбцы:

- `sequence_id` — идентификатор последовательности;
- `observations` — наблюдения через пробел.

Пример:

```csv
sequence_id,observations
seq_1,walk shop clean
```

## Формат выходного файла

`output10.csv` содержит:

- строки с типом `transition` — вероятности переходов между состояниями и их текстовую визуализацию;
- строки с типом `sequence_result` — исходную последовательность наблюдений, найденную последовательность состояний и итоговую вероятность.

## Запуск

Перейдите в папку `lab10` и выполните:

```bash
python icslab10.py
```

После запуска файл `output10.csv` будет создан или перезаписан автоматически.
