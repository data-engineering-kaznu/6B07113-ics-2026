# ЛЗ 10. Вероятностный подход к обработке последовательных данных

## Цель работы

Познакомиться с моделями Маркова и скрытыми марковскими моделями (HMM) для анализа последовательных данных.

## Теоретическая часть

### 1. Модели Маркова

Модель Маркова описывает последовательность состояний, где следующее состояние зависит от текущего состояния. Такой подход используется для прогнозирования последовательностей и анализа процессов, которые меняются во времени.

### 2. Скрытые марковские модели

Скрытая марковская модель применяется, когда реальные состояния системы напрямую не наблюдаются. Вместо этого доступны наблюдения, которые зависят от скрытых состояний.

Основные компоненты HMM:

- скрытые состояния
- наблюдения
- начальные вероятности состояний
- вероятности переходов между состояниями
- вероятности наблюдений для каждого состояния

### 3. Алгоритм Витерби

Алгоритм Витерби позволяет найти наиболее вероятную последовательность скрытых состояний по заданной последовательности наблюдений.

## Практическая часть

В работе реализована простая HMM для анализа последовательности действий человека и определения наиболее вероятной последовательности погоды.

Скрытые состояния:

- `Sunny`
- `Rainy`

Наблюдения:

- `walk`
- `shop`
- `clean`

В программе выполняются:

1. задание начальных вероятностей, матрицы переходов и матрицы наблюдений
2. поиск наиболее вероятной последовательности состояний алгоритмом Витерби
3. вывод таблицы вероятностей по шагам
4. визуализация матрицы переходов
5. визуализация вероятностей состояний во время декодирования
