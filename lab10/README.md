# Лабораторная работа 10

## Тема
Вероятностный подход к обработке последовательных данных: модели Маркова и скрытые марковские модели (HMM).

## Цель работы
Познакомиться с моделями Маркова и скрытыми марковскими моделями для анализа последовательных данных, применить алгоритм Витерби и визуализировать вероятности переходов.

## Состав папки
- `lab10_hmm.py` - основной код лабораторной работы.
- `weather_hmm_dataset.csv` - датасет с последовательностями состояний погоды и наблюдений.
- `transition_probabilities.png` - график вероятностей переходов между скрытыми состояниями.
- `emission_probabilities.png` - график вероятностей эмиссии наблюдений.

## Описание датасета
В работе используется собственный учебный датасет, состоящий из 5 последовательностей по 8 шагов в каждой.

Столбцы:
- `sequence_id` - номер последовательности.
- `step` - порядковый номер наблюдения.
- `weather` - скрытое состояние: `Sunny`, `Cloudy`, `Rainy`.
- `activity` - наблюдаемое действие: `walk`, `picnic`, `shop`, `study`, `clean`.

Идея датасета:
- скрытое состояние описывает фактическую погоду;
- наблюдение описывает действие человека;
- по последовательности действий модель пытается восстановить наиболее вероятную последовательность погодных состояний.

## Что реализовано в коде
1. Загрузка CSV-файла с последовательностями.
2. Разделение данных на обучающую и тестовую части по `sequence_id`.
3. Оценка начальных вероятностей, матрицы переходов и матрицы эмиссии с лапласовским сглаживанием.
4. Применение алгоритма Витерби к тестовой последовательности наблюдений.
5. Сравнение предсказанной последовательности состояний с реальной.
6. Визуализация матрицы переходов и матрицы эмиссии.

## Краткое объяснение методов
### Модель Маркова
Модель Маркова предполагает, что следующее состояние зависит только от текущего состояния. Для погоды это означает, что вероятность завтрашней погоды зависит от сегодняшней.

### Скрытая марковская модель
В HMM истинные состояния скрыты. Мы наблюдаем только косвенные признаки. В этой лабораторной работе скрытые состояния - это погода, а наблюдения - это действия человека.

### Алгоритм Витерби
Алгоритм Витерби находит наиболее вероятную последовательность скрытых состояний по заданной последовательности наблюдений. Он учитывает:
- начальные вероятности;
- вероятности переходов между состояниями;
- вероятности появления наблюдений в каждом состоянии.

## Ход выполнения работы
1. Подготовлен датасет из нескольких погодных последовательностей.
2. На основе обучающих последовательностей рассчитаны вероятности переходов между состояниями.
3. Рассчитаны вероятности эмиссии наблюдений для каждого скрытого состояния.
4. Для тестовой последовательности наблюдений выполнено декодирование с помощью алгоритма Витерби.
5. Полученные вероятности представлены в виде тепловых карт.

После запуска программа выводит:
