# Лабораторная работа 10

Тема: скрытая марковская модель (HMM), алгоритм Витерби и визуализация переходов.

В работе реализовано:

- простая HMM для анализа последовательности наблюдений;
- алгоритм Витерби для нахождения наиболее вероятной последовательности скрытых состояний;
- текстовая визуализация матрицы вероятностей переходов.

## Постановка задачи

Рассматривается пример предсказания погоды по наблюдаемым действиям:

- скрытые состояния: `Sunny`, `Rainy`;
- наблюдения: `walk`, `shop`, `clean`.

Модель использует:

- начальные вероятности состояний;
- вероятности переходов между состояниями;
- вероятности появления наблюдений в каждом состоянии.

## Алгоритм Витерби

Алгоритм последовательно вычисляет наиболее вероятный путь скрытых состояний:

1. Инициализирует вероятности для первого наблюдения.
2. Для каждого следующего наблюдения перебирает все возможные предыдущие состояния.
3. Сохраняет лучший предыдущий переход.
4. В конце восстанавливает наиболее вероятную цепочку состояний.

Для устойчивости вычислений применяются логарифмы вероятностей.

## Визуализация переходов

Вероятности переходов выводятся в виде матрицы:

- строки - текущее состояние;
- столбцы - следующее состояние;
- значения - вероятность перехода.
