# Лабораторная работа №10: Вероятностный подход к обработке последовательных данных

## Цель работы
Познакомиться с моделями Маркова и скрытыми марковскими моделями (HMM) для анализа последовательных данных.

## Теоретическая часть
### Модели Маркова
- Состояние системы зависит от предыдущего состояния.
- Применяются для прогнозирования последовательностей.

### Скрытые марковские модели
- Состоят из скрытых состояний, наблюдений и вероятностей переходов.
- Для анализа последовательностей используются алгоритмы Витерби и forward.

## Практическая часть
В работе реализована простая скрытая марковская модель для предсказания погодных состояний по наблюдаемым действиям.

Скрипт:
- задает вероятности начальных состояний, переходов и эмиссий;
- находит наиболее вероятную последовательность скрытых состояний алгоритмом Витерби;
- вычисляет полную вероятность наблюдений алгоритмом forward;
- строит визуализацию матрицы переходов состояний.

## Как запустить
```bash
python lab10.py
```
