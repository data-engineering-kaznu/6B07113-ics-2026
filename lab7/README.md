# Лабораторная работа №7: Генетические алгоритмы

## Цель работы
Изучить принципы работы генетических алгоритмов и их применение для оптимизации сложных задач.

## Теоретическая часть
### Генетические алгоритмы
Основные этапы: инициализация, селекция, кроссовер, мутация.
Понятия: хромосома, популяция, фитнес-функция.

### Применение
- Оптимизация функций.
- Решение комбинаторных задач (например, задача о рюкзаке).

## Практическая часть
Реализуйте генетический алгоритм для оптимизации функции Розенброка.
Выполните настройку параметров: вероятность мутации, размеры популяции.
Проанализируйте влияние параметров на результат.
