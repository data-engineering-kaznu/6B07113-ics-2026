# Лабораторная работа №6: Методы эвристического поиска

### Описание
Цель работы — изучение и реализация алгоритмов эвристического поиска для нахождения пути в лабиринте.

Алгоритмы:
1. Жадный поиск (Greedy Search) — выбирает путь на основе оценки расстояния до цели.
2. Алгоритм A* (A-star) — находит кратчайший путь, учитывая как пройденное расстояние, так и оценку до цели.

### Используемые библиотеки
- csv (работа с файлами)
- heapq (очередь с приоритетами)

### Структура файлов
- search_lab6.py — основной код программы.
- input6.csv — входная матрица лабиринта (S - старт, E - финиш, 0 - проход, 1 - стена).
- output6.csv — результаты работы: длина пути и количество проверенных узлов.

### Как запустить
1. Подготовьте файл input6.csv с матрицей лабиринта.
2. Запустите скрипт через терминал:
   python search_lab6.py
3. Проверьте файл output6.csv для сравнения эффективности алгоритмов.

### Результаты
- Жадный поиск: обычно работает быстрее, но может найти не самый короткий путь.
- A*: гарантирует нахождение кратчайшего пути за счет использования функции f(n) = g(n) + h(n).
