# Лабораторная работа 8: Генетический алгоритм

## Что реализовано

В `icslab7.py` реализован генетический алгоритм для оптимизации функции Розенброка:

- хромосома состоит из двух генов: `x` и `y`;
- начальная популяция создается случайно в диапазоне от `-3` до `3`;
- используется турнирная селекция;
- используется арифметический кроссовер;
- мутация изменяет гены с заданной вероятностью;
- сохраняется элитная особь каждого поколения;
- результаты нескольких экспериментов читаются из `input8.csv` и записываются в `output8.csv`.

## Формат входного файла

`input8.csv` должен содержать столбцы:

- `run_id` — имя эксперимента;
- `population_size` — размер популяции;
- `mutation_rate` — вероятность мутации;
- `generations` — количество поколений;
- `crossover_rate` — вероятность кроссовера;
- `seed` — зерно генератора случайных чисел для повторяемости результата.

## Формат выходного файла

В `output8.csv` записываются:

- параметры запуска;
- лучшие найденные значения `x` и `y`;
- значение функции Розенброка;
- расстояние до оптимальной точки `(1, 1)`;
- краткий комментарий о влиянии параметров.

## Запуск

Перейдите в папку `lab8` и выполните:

```bash
python icslab7.py
```

После запуска результаты будут записаны в `output8.csv`.
