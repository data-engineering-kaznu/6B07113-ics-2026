# Лабораторная работа №8: Создание игр с помощью искусственного интеллекта

## Цель работы
Создать алгоритмы искусственного интеллекта для игр на основе поиска и стратегии.

## Теоретическая часть
### ИИ в играх
- Минимакс-алгоритм.
- Альфа-бета-отсечение.

### Применение
- Настольные игры (крестики-нолики, шахматы).

## Практическая часть
Реализуйте игру "Крестики-нолики".
Напишите алгоритм ИИ на основе минимакса.
Оптимизируйте алгоритм с помощью альфа-бета-отсечения.
Проверьте игру против ИИ.

## Как запустить
```bash
python lab8.py
```
