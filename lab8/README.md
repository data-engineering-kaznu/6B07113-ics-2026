# Лабораторная работа 8

Тема: создание игр с помощью искусственного интеллекта.

В работе реализована игра "Крестики-нолики" для человека против компьютера.
Компьютерный игрок использует алгоритм minimax для перебора ходов и
альфа-бета-отсечение для сокращения количества рассматриваемых состояний.

Что делает программа:

- выводит нумерацию клеток игрового поля;
- принимает ход пользователя;
- выбирает оптимальный ход ИИ;
- определяет победителя или ничью.

Алгоритмы:

- `minimax` оценивает все возможные ходы до конца игры;
- альфа-бета-отсечение ускоряет поиск, отбрасывая бесперспективные ветви.

Запуск:

```bash
python lab8.py
```

Структура:

- `lab8.py` — основная программа лабораторной работы;
- `README.md` — краткое описание.
