# Распознавание образов с помощью обучения без учителя (ЛЗ 3)

## 📌 Описание проекта
[cite_start]Данный проект представляет собой реализацию лабораторной работы по теме «Обучение без учителя»[cite: 1, 5]. [cite_start]Основная цель работы — выявление скрытых закономерностей и структуры данных (данные `X` без меток `y`) на примере задачи распознавания образов[cite: 3, 6, 7]. [cite_start]В качестве набора данных используется датасет рукописных цифр (Digits)[cite: 16].

## 📂 Структура проекта
* [cite_start]`lab4.py` — основной исполняемый скрипт с логикой подготовки данных, кластеризации и снижения размерности[cite: 17, 18].
* `Figure_1.png` — визуализация метода «локтя» для аналитического обоснования выбора количества кластеров (k=10).
* `Figure_2.png` — сравнение работы алгоритмов кластеризации, отображенное на двухмерной плоскости.
* [cite_start]`output.csv` — итоговый файл, содержащий исходные признаки объектов и метки кластеров, присвоенные алгоритмами (сегментация данных)[cite: 13].

## 🛠 Используемые методы и алгоритмы
В соответствии с теоретической базой в скрипте реализованы следующие методы:

**1. [cite_start]Алгоритмы кластеризации**[cite: 8]:
* **K-means** — алгоритм, разделяющий данные на заранее заданное число кластеров[cite: 9, 17].
* [cite_start]**DBSCAN** — плотностной алгоритм, способный находить кластеры произвольной формы[cite: 9, 17].

**2. [cite_start]Методы снижения размерности**[cite: 10]:
[cite_start]Применяются для визуализации многомерных данных[cite: 14]:
* [cite_start]**PCA (Метод главных компонент)**[cite: 11, 18].
* **t-SNE** — используется для наиболее качественного отображения локальных структур данных на итоговом графике[cite: 11].

## 📊 Оценка качества
Оценка качества кластеризации выполняется с помощью **метрики силуэта** (Silhouette Score)[cite: 19]. 
* В ходе выполнения алгоритм рассчитывает коэффициент силуэта для K-means (в данном запуске он составил `0.139`) и выводит его в консоль, а также на итоговый график.
