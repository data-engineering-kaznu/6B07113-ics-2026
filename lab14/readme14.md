# Лабораторная работа 14: Обучение с подкреплением

## Цель

Ознакомиться с базовыми принципами обучения с подкреплением и реализовать простой алгоритм Q-learning для управления агентом в дискретной среде.

## Используемые методы и подходы

- чтение входных параметров и запись результатов в CSV с помощью стандартного модуля `csv`;
- моделирование простой среды Line World с дискретными состояниями;
- применение алгоритма Q-learning для обновления Q-таблицы;
- выбор действий по схеме exploration/exploitation;
- построение итоговой стратегии на основе обученных Q-значений.

## Краткое описание выполнения

Во входном файле `input14.csv` задаются параметры среды:

- `states` — количество состояний;
- `goal_state` — целевое состояние;
- `episodes` — число обучающих эпизодов.

Скрипт `icslab14.py`:

1. считывает и проверяет параметры из `input14.csv`;
2. создаёт простую среду, где агент может двигаться влево или вправо;
3. обучает агента методом Q-learning;
4. определяет лучшую стратегию по обученной Q-таблице;
5. сохраняет Q-значения и найденный путь в `output14.csv`.

Такой пример демонстрирует основные идеи обучения с подкреплением без использования внешних библиотек, поэтому проект остаётся простым и устойчивым к ошибкам запуска.

## Файлы проекта

- `icslab14.py` — основной исполняемый скрипт;
- `input14.csv` — входные параметры среды;
- `output14.csv` — результаты обучения и лучшая стратегия;
- `readme14.md` — описание лабораторной работы.

## Запуск

```bash
python icslab14.py
```

После запуска программа обучает агента и перезаписывает `output14.csv` актуальными результатами.
