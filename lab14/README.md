## Теоретическая часть

### Обучение с подкреплением
Обучение с подкреплением - это подход, при котором агент взаимодействует со средой, выполняет действия, получает награды и постепенно учится выбирать стратегию, максимизирующую суммарную награду.

Основные элементы:
- **агент** - тот, кто принимает решение;
- **среда** - то, с чем взаимодействует агент;
- **состояние** - описание текущей ситуации;
- **действие** - возможный выбор агента;
- **награда** - численная оценка результата действия.

### Q-learning
Q-learning - это алгоритм, который оценивает полезность пары `(состояние, действие)` и обновляет эту оценку по формуле:

`Q(s, a) = Q(s, a) + alpha * (reward + gamma * max(Q(s', a')) - Q(s, a))`

где:
- `alpha` - скорость обучения;
- `gamma` - коэффициент дисконтирования будущих наград;
- `s` - текущее состояние;
- `a` - текущее действие;
- `s'` - следующее состояние.

### Почему используется собственная среда
В задании предлагается использовать `gym` и среду `CartPole`. Однако в локальной среде библиотеки `gym` и `gymnasium` отсутствуют. Чтобы лабораторная работа запускалась без дополнительных установок и оставалась самодостаточной, была реализована компактная учебная среда `BalanceBeamEnv`, имитирующая задачу удержания равновесия.

## Описание среды `BalanceBeamEnv`
Среда моделирует простую одномерную задачу баланса:
- у агента есть положение на отрезке;
- есть скорость, которая меняется под действием выбранной команды;
- если положение выходит за допустимые границы, эпизод завершается;
- если агент выдерживает `200` шагов, эпизод считается успешно пройденным.

Действия агента:
- `-1` - толкнуть влево;
- `0` - ничего не делать;
- `1` - толкнуть вправо.

Состояние описывается парой:
- положение;
- скорость.

Такая постановка позволяет сохранить суть задачи управления и использовать Q-learning в дискретном пространстве состояний.

## Что реализовано в коде
1. Создана среда `BalanceBeamEnv`.
2. Реализовано кодирование состояния в индекс Q-таблицы.
3. Реализован алгоритм Q-learning.
4. Использована `epsilon-greedy` стратегия исследования среды.
5. Выполнено обучение на 2000 эпизодах.
6. Выполнена отдельная оценка обученного агента.
7. Построены графики наград и длительности эпизодов.
8. Построена тепловая карта стратегии агента.
9. Сохранён журнал обучения в CSV.

## Параметры обучения
- число эпизодов: `2000`;
- коэффициент обучения `alpha = 0.1`;
- коэффициент дисконтирования `gamma = 0.99`;
- начальное значение `epsilon = 1.0`;
- минимальное значение `epsilon = 0.05`;
- постепенное уменьшение `epsilon`.

## Ход выполнения работы
1. Создана дискретная среда удержания баланса.
2. Для всех состояний и действий инициализирована Q-таблица.
3. На каждом эпизоде агент исследует среду и обновляет значения Q.
4. По мере обучения доля случайных действий уменьшается.
5. После завершения обучения агент тестируется без случайности.
6. Результаты сохраняются в графики и CSV.
