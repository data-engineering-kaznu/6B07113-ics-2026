# Лабораторная работа №14: Обучение с подкреплением

## Цель работы
Ознакомиться с базовыми принципами обучения с подкреплением и реализовать алгоритм Q-learning для управления агентом в задаче балансировки.

## Теоретическая часть
- Обучение с подкреплением рассматривает агента, который взаимодействует со средой и получает награду за свои действия.
- Q-learning оценивает полезность пары «состояние-действие» и постепенно улучшает стратегию выбора действий.
- Исследование среды выполняется через `epsilon-greedy` стратегию: часть действий выбирается случайно, часть — по текущей лучшей оценке.
- Для непрерывных состояний часто используют дискретизацию, чтобы хранить значения Q-функции в таблице.

## Практическая часть
В работе реализована автономная среда, близкая по смыслу к задаче `CartPole`, и обучен агент методом Q-learning без использования `gym`.

Скрипт:
- моделирует движение тележки и отклонение шеста;
- дискретизирует непрерывное состояние на интервалы;
- обучает Q-таблицу по схеме `epsilon-greedy`;
- оценивает качество стратегии на жадном запуске;
- сохраняет график обучения, тепловую карту политики и траекторию демонстрационного эпизода.

Такой вариант соответствует логике задания: агент обучается удерживать систему в устойчивом состоянии и достигает длительности эпизода порядка 200 шагов и выше.

## Файлы
- `lab14.py` — основной скрипт.
- `learning_curve.png` — динамика длины эпизодов и награды при обучении.

## Как запустить
```bash
python lab14.py
```
