 Почему разные длины пути
Метод	Как работает	Результат
Greedy	Смотрит только на эвристику h(n) → “куда ближе к цели”	Быстро доходит, может идти зигзагами, путь длиннее
A*	Смотрит на g(n) + h(n) → “короткий путь до текущей + эвристика до цели”	Медленнее, но короткий и оптимальный путь
В моем случае: Greedy 199 шагов, A* 145 шагов → короче почти на 30%.
Greedy быстрее, потому что игнорирует длину пути.
A* чуть медленнее, но точнее.
