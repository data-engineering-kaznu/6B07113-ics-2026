# ЛЗ 6. Методы эвристического поиска

## Цель работы
Освоить эвристические методы поиска, включая жадный поиск и алгоритм A*.

## Теоретическая часть

### 1. Эвристический поиск
Эвристический поиск используется для ускорения нахождения решения задачи.  
В отличие от полного перебора, он не просматривает все возможные варианты, а использует функцию оценки.

### 2. Функция оценки h(n)
Функция h(n) показывает, насколько текущая вершина близка к цели.  
В данной работе используется манхэттенское расстояние:

h(n) = |x1 - x2| + |y1 - y2|

### 3. Жадный поиск
Жадный поиск выбирает ту вершину, которая кажется ближайшей к цели по эвристике h(n).  
Он работает быстро, но не всегда находит оптимальный путь.

### 4. Алгоритм A*
Алгоритм A* использует функцию:

f(n) = g(n) + h(n)

где:
- g(n) — стоимость пути от старта до текущей вершины
- h(n) — эвристическая оценка до цели

Алгоритм A* считается более точным и обычно находит кратчайший путь.

## Практическая часть
В работе реализованы:
1. Жадный поиск для нахождения выхода из лабиринта
2. Алгоритм A* для того же лабиринта
3. Сравнение их производительности
4. Визуализация процесса поиска
