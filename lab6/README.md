# Лабораторная работа 6
## Обнаружение и отслеживание объектов

### Цель работы
Научиться обнаруживать объект на видео и отслеживать его движение с помощью методов компьютерного зрения.

### Что реализовано
- загрузка видеофайла;
- ручной выбор мяча на первом кадре;
- автоматическое определение цветового диапазона объекта в HSV;
- обнаружение мяча по цветовой маске и контурам;
- отслеживание объекта с помощью OpenCV tracker (`CSRT`, `KCF` или `MOSSE`);
- повторное обнаружение объекта, если трекер его потерял;
- сохранение результата в новый видеофайл.

### Используемые библиотеки
- `OpenCV`
- `numpy`

### Идея решения
В работе использован гибридный подход:

1. На первом кадре пользователь выделяет мяч.
2. Программа анализирует цвет объекта в пространстве HSV.
3. На основе цвета выполняется первичное обнаружение мяча.
4. Далее объект сопровождается трекером OpenCV.
5. Если трекер теряет объект, программа пытается найти его заново с помощью цветового детектора.

Такой подход хорошо подходит для видео с мячом, потому что объект обычно небольшой, быстро движется и не всегда удобно обнаруживается тяжелыми нейросетевыми моделями.


### Запуск
Если видео лежит в корне проекта и называется `5275695-uhd_2160_4096_25fps.mp4`, можно запускать так:

```bash
cd lab12
python main.py
```

Если нужно указать свой файл:

```bash
cd lab12
python main.py --video ../my_video.mp4
```

### Параметры запуска
- `--video` — путь к входному видео;
- `--tracker` — тип трекера: `CSRT`, `KCF`, `MOSSE`;
- `--max-width` — уменьшение ширины кадра для ускорения обработки;
- `--output` — имя выходного файла с результатом;
- `--min-radius` — минимальный радиус мяча для детектора;
- `--refresh-interval` — как часто обновлять трекер по результату детектора.

Пример:

```bash
python main.py --video ../5275695-uhd_2160_4096_25fps.mp4 --tracker CSRT --output tracked_ball.mp4
```

### Как работать с программой
1. После запуска откроется первый кадр видео.
2. Мышкой выделите мяч прямоугольником.
3. Нажмите `Enter` или `Space` для подтверждения выбора.
4. Начнется отслеживание объекта.
5. Для выхода нажмите `Esc` или `q`.

### Результат
Программа должна:
- находить мяч на видео;
- удерживать рамку вокруг объекта;
- заново обнаруживать его, если трекер временно потерял цель;
- сохранять видео с размеченным результатом.
