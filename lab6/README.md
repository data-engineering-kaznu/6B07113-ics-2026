# Данные

В работе используется искусственно созданный лабиринт, представленный в виде двумерного массива.

Значения в массиве:

0 — свободная клетка (проход)  
1 — препятствие (стена)  

Начальная точка: (0, 0)  
Конечная точка: (4, 6)  


# Описание

Данная лабораторная работа демонстрирует применение эвристических алгоритмов поиска пути в лабиринте.

В ходе работы выполняются следующие этапы:

создание лабиринта;
реализация жадного алгоритма поиска;
реализация алгоритма A*;
сравнение эффективности алгоритмов;
визуализация процесса поиска и найденного пути.


# Теоретическая часть

## Эвристический поиск

Эвристические алгоритмы используют функцию оценки, позволяющую быстрее находить решение по сравнению с полным перебором.

### Эвристическая функция

Используется манхэттенское расстояние:

|x1 - x2| + |y1 - y2|


# Реализованные алгоритмы

## Жадный поиск (Greedy Search)

Алгоритм выбирает вершину, которая находится ближе всего к цели.

Функция оценки:

f(n) = h(n)

Особенности:

не учитывает пройденный путь;
может находить неоптимальное решение;
работает быстрее, но менее точно.


## Алгоритм A*

Алгоритм учитывает как пройденный путь, так и расстояние до цели.

Функция оценки:

f(n) = g(n) + h(n)

где:

g(n) — стоимость пути от начальной точки  
h(n) — эвристическая оценка  

Особенности:

гарантирует нахождение кратчайшего пути;
более точный по сравнению с жадным алгоритмом.


# Оценка результатов

Сравнение алгоритмов проводится по:

количеству посещённых узлов;
длине найденного пути.

Ожидаемый результат:

A* посещает меньше узлов и находит более оптимальный путь.
